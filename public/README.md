# 🎓 Online Examination System

A full-stack web application that provides a simple and interactive platform for conducting online examinations. The system allows students to take timed exams, answer subject-specific questions, and receive instant results and performance feedback.

**🚀 Live Demo:** https://online-examination-system-l2h4.onrender.com/login.html
**📂 Source:** https://github.com/Parimal1004/MyProjects

---

## 1. Problem Statement

Traditional examinations require significant time and resources to conduct and evaluate. This project provides a digital examination platform that simplifies the process of conducting timed assessments, evaluating answers, and generating results automatically.

## 2. Objectives

* Provide an interactive platform for online examinations
* Implement timed assessments with automatic submission
* Evaluate answers and generate results instantly
* Organize questions based on different subjects
* Provide a responsive interface for different devices

## 3. Tech Stack

| Layer           | Technology            |
| --------------- | --------------------- |
| Backend         | Node.js, Express.js   |
| Frontend        | HTML, CSS, JavaScript |
| Package Manager | npm                   |

## 4. Features

* **Timed Exams** — Countdown timer for each examination
* **Auto Submission** — Exam is automatically submitted when the timer expires
* **Instant Evaluation** — Displays score, percentage, and grade immediately
* **Multiple Subjects** — Supports subjects such as Java, Python, DSA, and HTML
* **Question Navigation** — Navigate through questions easily
* **User Authentication** — Basic login/access flow
* **Responsive Design** — Works across desktop and mobile devices

## 5. Application Workflow

1. User accesses the examination system
2. Selects the desired subject/exam
3. Exam begins with a countdown timer
4. User answers and navigates through questions
5. Exam is automatically submitted when time expires
6. Answers are evaluated automatically
7. Final score, percentage, and grade are displayed
