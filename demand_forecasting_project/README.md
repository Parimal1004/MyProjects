# 📈 Demand Forecasting

A machine learning project that predicts product demand using historical data and an **XGBoost regression model**. The project includes data preprocessing, exploratory data analysis, model development, and a deployed web application.

## 🚀 Live Demo

👉 [View the Deployed Application](https://demand-forecasting-app-btjg.onrender.com/)

## ✨ Features

* Historical demand data analysis
* Data preprocessing and feature encoding
* Exploratory Data Analysis and visualization
* Demand prediction using XGBoost
* Interactive web application
* Deployed using Render

## 🛠️ Technologies Used

* Python
* Pandas & NumPy
* Scikit-learn
* XGBoost
* Streamlit
* Matplotlib & Seaborn
* Jupyter Notebook

## 📂 Project Structure

* `app.py` — Web application
* `analysis.ipynb` — Exploratory Data Analysis
* `machine_learning.ipynb` — Machine learning workflow
* `xgboost_demand_model.pkl` — Trained XGBoost model
* `label_encoders.pkl` — Saved preprocessing encoders
* `demand_forecasting.csv` — Original dataset
* `preprocessed_demand_forecasting_data.csv` — Processed dataset
* `requirements.txt` — Project dependencies

## 🎯 Objective

To apply machine learning techniques to forecast product demand and help businesses make better **inventory, planning, and decision-making**.
